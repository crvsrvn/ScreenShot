## 环境 {#env}

- Windows 10 IoT Enterprise LTSC 2021（19044）x64，两台 2560×1440（125%）显示器；整个开发期间桌面处于锁屏状态。
- Qt 6.12.0 msvc2022_64，MSVC 14.51（VS 2026 Build Tools），C++20，CMake 3.28 预设 `win-debug` / `win-release-test` / `win-release`。
- 第三方（FetchContent，静态链接，构建期联网，运行期零网络）：ZXing-C++ 2.3.0（条码）、QuickJS-ng 0.9.0（脚本）、libwebp 1.6.0（动画 WebP）。MP4 / AAC 用 Media Foundation，声音用 WASAPI，摄像头用 Media Foundation 源读取器，OCR 用 Windows.Media.Ocr，均为系统自带。
- 打包：windeployqt 收集运行时（含 MSVC 运行库）→ 绿色版 zip；Inno Setup 6（winget 安装）→ 安装包。

## 各里程碑交付的内容 {#delivered}

### M1 ~ M4（基础功能）

- 截图：热键触发冻结全部显示器画面（DXGI，GDI 兜底），混合缩放逐像素精确；UI 元素 / 窗口检测在工作线程带超时；框选、调整、放大镜、取色、历史；输出到剪贴板 / 文件 / 贴图；单实例与命令转交；托盘、自启动、配置、日志、崩溃转储。
- 标注：矢量标注文档（矩形、椭圆、线条 / 箭头、铅笔、荧光笔、马赛克、模糊、文字、橡皮），选中 / 移动 / 缩放 / 旋转，撤销重做，工具栏，输出时栅格化。
- 贴图：物理像素定位、滚轮缩放、透明度、点穿、关闭 / 恢复、文本贴图、Alt 拖动；CPU 渲染满足性能指标。
- 滚动截图：区域锁定、稳定帧检测、行哈希拼接、自动滚动与到底判定、纯色 / 重复内容拒绝并给出原因、横向拼接、边框与预览窗口不参与捕获。

### M5 ~ M6（P1 / P2 需求）

- 截图：截图后动作组合、自定义截图对话框与预设、快捷截图、层级元素切换、尺寸输入与固定比例、指针截取、圆角 / 阴影 / 边框、白板与透明白板、模式轮换（静态 / 滚动 / 录制）、区域历史、检测排除列表、外观与放大镜设置、辅助线、HDR 色调映射。
- 输出：复制为文件、自动质量与透明通道、路径变量与修饰符、自动保存与清理、打印 / PDF 分页、编码预览、保存后复制、元数据、外部命令。
- 标注：右键贴合元素、线型与圆角、箭头样式、文字装饰与换行、序号、放大标注、色板、框选多选、自定义工具栏、扇形、端点样式、智能擦除、自动马赛克、聚光灯、水印。
- 贴图：HTML / 颜色 / 文件贴图、文字选择与 OCR 可选文字、替换策略、吸附、灰度反色、缩略图、裁剪、分组与组管理、重复贴图策略、亮度、锁定、标题、透明背景、拖出内容、虚拟桌面、独显、重启恢复。
- 识别与动作：Windows OCR（语言、精准模式、排版、标点）、表格导出 Excel、二维码 / 条码识别与生成、动作系统与热键、命令行接口与 `--wait`、QuickJS 脚本、全局鼠标截图、热角、修饰键双击、粘贴为图像 / 纯文本、配置导入导出与高级配置。

### M7（屏幕录制）

- 录制会话：选区边框 + 工具栏（开始 / 暂停 / 继续 / 停止 / 重录 / 计时 / 延迟），帧率 5 ~ 60，画质轻量 / 标准 / 原始，边框、工具栏与标注层不参与捕获。
- 普通模式：帧写入磁盘目录（`recording.json` 索引每 2 s 落盘），停止后进入回放窗口；快速模式：边录边经 Media Foundation 写 MP4，停止后直接快速保存并复制为文件。
- 导出：GIF（自研中位切分量化 + LZW）、动画 WebP（libwebp）、MP4（H.264 + AAC）；回放窗口支持播放 / 暂停 / 跳转 / 倍速、裁剪开头结尾、进度条 / 文字 / 倒计时叠加、保存 / 快速保存 / 复制 / 丢弃。
- 声音：麦克风与系统声音（WASAPI 环回）分别调音量，统一重采样到 48 kHz 单声道后混合；无播放时补零保持对齐。
- 录制中标注（透明标注层，右键撤销）、鼠标点击涟漪 / 滚轮箭头 / 按键标签（动画时长可调，经低级钩子记录）、摄像头画中画（位置与大小可调）。
- 崩溃恢复：启动时扫描未完成的录制目录，询问后打开回放窗口；索引落后于磁盘帧时按帧率补齐时间戳。

### M8（收尾）

- 验收与非功能需求的用例：30 步撤销重做无残影（`AC-04`）、输入法事件输入中文并旋转导出一致（`AC-03`）、命令行 `--wait` 场景（`AC-12`）、启动耗时场景（`NFR-03`）、系统版本门槛（`NFR-11`，低于 19041 启动即提示退出）、设置项可访问名称与说明（`NFR-14`）。
- 打包（`NFR-12`）：`tests/package/check_package.py` 生成绿色版 zip 与 Inno Setup 安装包并检查 ≤ 50 MB、包内无 Qt Network；只在非 Debug 配置下运行。
- 已实现但此前未纳入范围的需求（各工具记住颜色、形状旋转、工具快捷键、一键禁用热键、选项说明、贴图尺寸限制、屏幕外贴图恢复）补入交付范围并核对用例。

## 如何构建与测试 {#howto}

```bash
scripts\build.cmd win-release-test
```

```bash
scripts\test.cmd win-release-test
```

- 只跑无需桌面的用例：`scripts\test.cmd win-release-test -LE e2e`；只跑端到端：`-L e2e`；打包：`-L package`（产物在 `build\win-release-test\dist`）。
- 发布构建：`scripts\build.cmd win-release`，然后运行 `tests\package\check_package.py`（参数见 `tests/CMakeLists.txt`）生成绿色版与安装包。
