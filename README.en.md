### ScreenShot

- A screenshot and pin tool: screen capture (including scrolling capture), annotation, pinning images to the screen, color picking, local recognition (OCR / QR code / barcode), and screen recording (GIF / WebP / MP4)
    - Fully offline: no network features and no network requests; no paywall, account, or ads
- Supports Windows 10 version 2004 (19041) or later x64 and Windows 11
    - The macOS 14.4+ code is written alongside but has not yet been built or tested on a Mac
